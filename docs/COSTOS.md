# Costos y publicación · consultado 31 de octubre de 2026

- **Sitio estático en GitHub Pages:** disponible con GitHub Free para repositorios públicos; sitio publicado hasta 1 GB, límite blando 100 GB/mes, 10 builds/hora en el flujo normal (no aplica del mismo modo a un workflow personalizado). Pages no ejecuta Python ni aloja agentes. No está destinado a SaaS comercial ni transacciones sensibles. [Documentación oficial](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits).
- **Agentes locales:** Ollama es software abierto y dispone de API local ([documentación](https://github.com/ollama/ollama)); Transformers puede ejecutar modelos en CPU. No hay tarifa por llamada en la máquina propia, pero hay consumo de electricidad, almacenamiento, memoria y tiempo. `smollm2:135m` en Ollama tiene un archivo publicado de 271 MB según [su ficha](https://ollama.com/library/smollm2:135m). La ficha de [SmolLM2-135M-Instruct](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct) señala predominio de inglés y posibles errores. Ningún proveedor paga la electricidad o hardware del usuario.
- **Cloudflare Workers AI, alternativa futura no implementada:** documentación oficial [Pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/) establece 10.000 neuronas gratuitas por día; Workers Paid cobra $0,011 por cada 1.000 neuronas por encima de la asignación. Requiere cuenta y su integración, controles de privacidad y facturación deben verificarse antes de utilizarla; no se verificó el requisito de tarjeta. Los cupos pueden cambiar. Este repositorio no incluye adaptador ni secretos de Cloudflare.
- **Servicios comerciales:** la aplicación no los implementa. En general pueden requerir cuenta, facturación y cobros por tokens; no se promete una cuota gratuita perpetua.

Para una aplicación pública con agentes se necesita un backend seguro alojado o un modelo en el dispositivo del usuario: GitHub Pages por sí solo sólo ofrece la versión estática sin conversación. Las opciones de hospedaje, autenticación y cómputo deben evaluarse separadamente; no hay garantía de $0 en producción.
