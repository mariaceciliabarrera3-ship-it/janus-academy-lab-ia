# Procedencia de datos y recuperación

La aplicación usa `activaciones_16.npz` compacto derivado del archivo completo `estudio_16_cabezas/datos/activaciones_16.npz`, cuyo SHA-256 es `014338c41f7904ad6809955db44a86503b9f9a3ebff16bb84586f518b1778248`. Sus valores `z` y `attention` fueron convertidos de float64 a float32 **sin cambiar ningún valor**, porque habían sido calculados originalmente en float32 y luego ampliados a float64. La pérdida, pasos, IDs, tokens y targets se copiaron sin modificación. Las matrices `residual_contribution` y `logits` no se incluyen: no las usan el laboratorio ni el verificador; el estudio completo se conserva por separado.

Los 13 checkpoints, el código de reconstrucción de las 16 cabezas, mapas completos y pruebas previas están en el archivo externo conservado por el usuario `estudio_16_cabezas.zip`, SHA-256 `998104338fcdebe987ee4a0bd6ef3932a2203e7364f402e3b95bd72059c1b8ca`. No existe una URL pública conocida: solicitar ese archivo a quien conserve las investigaciones. No se descarga automáticamente. Su estructura incluye `estudio_16_cabezas/insumos/checkpoints/`, `insumos/entradas.csv`, `codigo/extraer16.py` y `datos/activaciones_16.npz`.

Para verificar ese archivo externo: `sha256sum estudio_16_cabezas.zip`. Para repetir la extracción original, descomprimir y seguir su README, instalando Torch/NumPy/SciPy; no es necesario para ejecutar el Lab limpio. Para regenerar desde los datos incluidos los archivos `web/data/{z.bin,attention.bin,manifest.json}`, ejecutar `python scripts/build_data.py`. El `source_npz_sha256` del manifiesto web es el hash de **este NPZ compacto**, no el del archivo externo completo. `research/metricas.csv` y `pares.csv` son copias sin alterar del estudio; el manifiesto web los incorpora.
